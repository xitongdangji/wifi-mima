
第一种最低级使用万能钥匙或者软件傻瓜式一个个试密码，现代路由器有防护对密码输入的频率有限制

第二种要脸皮厚直接张嘴问密码

第三种是传统WiFi密码破解是在Linux系统中使用airodump-ng抓取握手包，获取握手包之后使用hashcat +密码字典计算哈希值撞包的方式暴力破解，密码本中没有正确匹配密码就会到导致破解失败。

第四种是在Linux系统中使用支持监听 注入 虚拟ap 的网卡建立邪恶双胞胎钓鱼页面诱导被攻击目标手动输入密码，达到窃取目标路由器密码的目的

第五种是使用BW16加普通esp32进行破解

第六种是现代最新 最高级 最灵活 使用ESP32-C5开发板破解WiFi密码


传统方式必须使用Linux电脑建立邪恶双胞胎钓鱼页面需要最低两个网卡配合，一个网卡建立ap钓鱼页面，另一个网卡不断的切换信道攻击目标2.4g和5g，airodump-ng抓取握手包破解还要懂得一些Linux终端命令的基础知识，对绝大多数人不友好。
旧方案BW16加普通esp32已过时，普通esp32只支持2.4g，BW16虽然支持2.4g和5g，但是无法同时攻击两个频段。硬件成本高软件编写难度大，需要两个单片机无缝配合，稳定性差。
ESP32-C5开发板对比传统方式破解WiFi密码优缺点，只需要一个单片机节省成本，一个普通人不需要掌握Linux命令就可以成为黑客，掌握了这非常酷的技能在好友面前非常有面，c5单片机只有银行卡一半的大小，插到充电宝上任何地点都可以工作。


ESP32-C5是一个单片机买回来是不可以直接破解WiFi密码，里面没有程序，需要烧录一个特殊的固件

固件内置邪恶双胞胎和wifi杀手
Evil Twin（邪恶双子 / 双胞胎攻击），属于无线社会工程学攻击，没有受过专业训练的99%都会上当，核心思路一句话：攻击者伪造一个和真实 Wi-Fi 完全同名的假热点，让别人误以为它是自家 WiFi 的热点，克隆目标路由器 AP 的 WiFi 名字并建一个假的开放热点，在攻击期间路由器2.4G和5G网络会完全瘫痪无法联网
wifi杀手Deauther 取消认证器功能模块可以把所有连接到当前 WiFi 的手机、笔记本电脑、智能手表等等客户端设备全部踢下线
esp32-c5 只需要 30 块钱左右比起买一些电脑网卡性价比拉满
为什么买 esp32-c5？因为只有 c5 开发板支持 5G 频段，现在大多数路由器都是双频的。其他的 esp32 开发板也可以使用 WiFi 钓鱼，只能攻击单频路由器，无法攻击双频的路由器，如果非要使用单频的esp32，还得需要Linux电脑的网卡进行攻击对方 5G 频段，非常麻烦，不如直接用c5
烧录固件也非常简单，买回来开发板使用 Type-C 数据线插电脑上就行了，跟卖家要驱动装上或者自己搜索引擎搜索CH341SER.EXE驱动。打开设备管理器就可以看到 com 串口了。
